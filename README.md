# PDF Editor Website
Open `index.html` in a modern browser.

Current demo features:
- PDF upload and page rendering
- Add/edit/drag text
- Font, size and color controls for added text
- Add images
- Draw a signature and place it
- Delete selected objects

For production-quality editing of existing PDF text while preserving embedded fonts, and for reliable PDF export, integrate a PDF editing engine (e.g. pdf-lib plus font embedding, or a server-side PDF engine).
